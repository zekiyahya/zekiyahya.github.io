Digital Epigraphy: Implementing Sumerian as Conceptual Art in Modern Web Architecture

Creative Direction: Zeki Yahya Year: 2026 Medium: Web DOM / HTML5

Project Overview

The contemporary architecture of the World Wide Web is predominantly optimized for living languages, rapid data consumption, and algorithmic monetization. Modern platforms treat text merely as transparent data streams to be parsed, index-mapped, and targeted. Digital Epigraphy challenges this paradigm by introducing an ancient, extinct linguistic system—Sumerian (ISO 639-3 sux)—directly into the foundational markup of modern HTML5 architecture.

Conceived as a theoretical and visual extension of cinematic stillness and existential philosophy, this project transforms the volatile Document Object Model (DOM) into "Digital Clay," establishing heavy, opaque monuments on a network built for ephemeral consumption.

Conceptual Framework

1. The DOM as Digital Clay

In ancient Mesopotamia, clay tablets served as enduring media carrying human memory across millennia. By mapping Sumerian cuneiform glyphs directly onto structural HTML elements, the code ceases to function purely as hidden technical utility. Instead, the code itself becomes a tangible artifact—an architectural medium where digital syntax meets ancient epigraphy.

2. Resistance to Algorithmic Surveillance

Commercial algorithms thrive on decipherable, real-time linguistic input to build behavioral profiles. Embedding an extinct language—devoid of modern commercial metadata—starves tracking scripts of monetizable data. It introduces a calculated friction into the User Experience (UX), subverting the seamlessness of surveillance capitalism through opaque, un-indexable artifacts.

"Transferring the melancholic stillness of human transience from the screen to the digital canvas: code re-imagined not as script, but as a monument carved in digital stone."

3. Cinematic Stillness in Code

Drawing from a visual tradition rooted in existential depth and meditative stillness, Digital Epigraphy approaches web structure not as a commercial interface, but as a cinematic frame. The presence of silent, extinct glyphs forces a contemplative pause, turning the act of web browsing into an archaeology of digital time.

Project Manifestation

This conceptual architecture manifests through live web implementations where layout structures, metadata tags, and visible content are bound together through ancient script integration.
