# Digital Epigraphy (SUX Markup)

*"Building the digital temple from the mud-bricks of antiquity."*

**Digital Epigraphy** (also referred to as **SUX Markup**) is a conceptual esoteric markup language. Operating at the intersection of media archaeology, web architecture, and cinematic stillness, it replaces standard HTML5 DOM nodes with extinct Sumerian cuneiform (ISO 639-3 sux).

This project is not designed for functional computation. It is an act of algorithmic resistance against the hyper-active flow of surveillance capitalism. By embedding an unreadable, non-monetizable script into the web's semantic structure, it forces a meditative, melancholic stillness—a digital clay tablet carrying profound existential weight, baked permanently into the browser's memory.

## Architecture & Syntax

The syntax is directly derived from authentic archaeological records, specifically the **Gudea Cylinders (Cylinder A)**, which detail the construction of a sacred structure from the ground up. Standard structural web tags are replaced by the foundational elements of a Sumerian temple.

| Sumerian Sign | HTML Equivalent | Semantic Meaning | Archaeological Reference |
| :---: | :---: | :--- | :--- |
| `𒋼` (TE) | `<html>` | Foundation / Root peg | [CDLI: P222399](https://cdli.mpiwg-berlin.mpg.de/artifacts/222399) |
| `𒊕` (SAG) | `<head>` | Head / Top / Metadata | [CDLI: P222399](https://cdli.mpiwg-berlin.mpg.de/artifacts/222399) |
| `𒂍` (E2) | `<body>` | House / Main Structure | [CDLI: P222399](https://cdli.mpiwg-berlin.mpg.de/artifacts/222399) |
| `𒋞` (SIG4) | `<div>` | Mud-brick / Structural block | [CDLI: P222399](https://cdli.mpiwg-berlin.mpg.de/artifacts/222399) |

## Structural Example

The following represents a closed system written in Digital Epigraphy. The metadata and absolute concepts reside in the "Head" (`𒊕`), while the visual and structural blocks are built mud-brick by mud-brick (`𒋞`) within the "House" (`𒂍`).

```xml
<𒋼>
    <𒊕>
        <!-- Metadata and existential weight reside here -->
    </𒊕>
    <𒂍>
        <𒋞>
            <!-- Content Block 1 -->
        </𒋞>
        <𒋞>
            <!-- Content Block 2 -->
        </𒋞>
    </𒂍>
</𒋼>
## Concept & Creative Direction

Conceived as a philosophical manifesto in code, Digital Epigraphy explores the tension between deep time and digital impermanence. It stands as a silent monolith within the digital noise, inviting the viewer to contemplate the ruins of the internet before they even occur.
